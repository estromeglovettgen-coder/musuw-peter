# Aurora Observation Guide

This file is an original Musuw product-review fixture. It contains no customer
data and makes no claim about a real organization.

## Observation sequence

The Aurora observation sequence begins with a horizon scan. Operators then
repeat the horizon scan once to confirm that the reference line is stable.
Record the Northstar calibration after the second horizon scan and before the
spectral review.

## Calibration record

The Northstar calibration phrase is **ORBITAL SAGE 4826**. The phrase must be
copied exactly into the observation record so a reviewer can distinguish
evidence retrieved from this source from general model knowledge.

## Evidence review

Every observation answer should remain bound to this source, identify the
relevant section, and expose a citation that a reviewer can open. If the source
does not contain an answer, the response should say that the evidence is
insufficient instead of inventing a result.
