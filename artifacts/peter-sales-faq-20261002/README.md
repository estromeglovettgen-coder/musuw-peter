# Peter 课程销售常见问答

`faq.json` 包含 50 条 FAQ。每条由主问题、两个口语相似问题、可直接发送的回答和一个分类标签组成。JSON 外层为 `metadata` 与 `faqs`；来源说明集中放在 `metadata.provenance`，不加入每条客户话术。

这些内容是根据本批课程设定和销售流程人工编写的业务演示问答，不是从 Peter 微信中导出的历史原话，也不构成实际成交或付款证明。它们模拟的是 Peter 作为课程销售人员的售前与交接场景，关系问题用于判断购买需求，不能把售前对话扩展成长期情感辅导。

## 统一课程设定

- 课程名称：沟通与关系实践课。
- 价格与周期：1980 元/期，四周。
- 交付：每周一节可回看课程，每周三次 15—20 分钟短练习，固定窗口集中反馈。

以上是本批业务演示假设，与 `../peter-sales-demo-20261001/conversations.json` 的来源说明和 `sales-methods.md` 一致；不声称是 Peter 已发布的正式报价或服务政策。

没有新增一对一陪跑、无限私聊、代聊、分期、折扣、退款条款、发票承诺、稀缺名额或效果保证。具体目录、开课日期、付款渠道、提交方式、匿名要求、延期和退款政策需要核对当期产品说明。涉及未知政策的 FAQ 会先提出核对步骤，不替产品作出承诺。

## 使用边界

导入时只将 `faqs` 中的 `question`、`similar_questions`、`answer` 和 `tag` 映射到原生 FAQ 字段。来源说明保留在此目录与 JSON metadata 中，不能假称为 Peter 原始聊天。

FAQ 回答是按问题语境使用的模板。匹配“我已经付款”不能替代到账核对，匹配“资料收到了”也不能覆盖客户原始记录中的相反情况。具体客户的需求、付款、交接与跟进许可，仍以该客户的最新原始资料为准。

本任务只制作本目录两份内容文件，没有修改应用代码、服务器、客户资料、模型或智能体配置，也没有执行在线导入。
