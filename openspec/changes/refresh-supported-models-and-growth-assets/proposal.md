## Why

Musuw's September launch needs accurate acquisition material and a current model catalog. Six managed capability entries now have confirmed same-purpose replacements. Marketing currently claims webpage import on the free plan although the application correctly requires a paid plan. Refresh these existing surfaces without changing plan rules, customer data, or the release safety contract.

## What Changes

- Add one bilingual public `/press` page using the existing storefront, with verified public product media, captioned feature showcases and a whitelisted download archive.

- Verify every managed model against current first-party catalogs; upgrade supported same-family entries and synchronize provider IDs, labels, reasoning controls and defaults.
- Preserve stable platform IDs, saved selections, manual models and the embedding space used by existing knowledge bases. Keep current Pro/preview entries where no suitable successor exists.
- Correct bilingual free-plan import descriptions and prepare factual product demonstrations and directory material focused on qualified traffic and paid conversion.
- Record source evidence, real interface acceptance, publication status, and exact-SHA staging/production delivery. No paid marketing, artificial engagement, or duplicated unsolicited posts.

## Capabilities

### New Capabilities

- `supported-model-refresh`: A verified, compatible refresh of the existing managed model catalog, including labels and native capability request formats.
- `accurate-growth-materials`: Product acquisition copy and demonstrations match current plan entitlements and actual product behavior, with distinct publication and review states.

### Modified Capabilities

None. Existing specifications are recorded in historical change directories rather than canonical `openspec/specs`; this change preserves those established selection, entitlement, and deployment contracts.

## Impact

Existing WeKnora model YAML, model metadata/UI utilities, built-in fallback configuration, related tests, upstream provenance ledger, and storefront marketing copy. No new service, database schema, provider integration, entitlement change, root license change, or vector migration. External submissions use established accounts and free platform workflows; measured results must not be conflated with drafts or pending reviews.
