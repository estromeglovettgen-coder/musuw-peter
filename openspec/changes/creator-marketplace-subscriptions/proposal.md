## Why

Musuw users need to subscribe to reviewed knowledge services and immediately use their dedicated agents without copying private assets or changing their platform membership. The initial release proved real Paddle Sandbox payment, authorization, and chat behavior on staging within the authorized ten-hour execution window (2026-09-22 01:11–11:11 UTC). The authorized follow-up completes Taylor content, adds genuine free examples, and consolidates subscription management in orders. The next authorized refinement exposes purchased libraries in the knowledge workspace with read-only published Wiki and graph browsing.

## What Changes

- Add a Musuw-styled market and featured services on the existing app homepage, with Taylor and clearly labeled sandbox fixtures.
- Let effective Max members submit existing KB/agent references and private contact/authorization information for system-admin review.
- Sell each paid reviewed service as an independent monthly/yearly Paddle subscription; default annual price is ten monthly payments for twelve months of access.
- Unify purchased services, transaction history, and customer-portal subscription management under order management.
- Start an existing native chat with the purchased service's agent/KB selected and DeepSeek Flash by default; validate buyer access on every execution while keeping billing and chat ownership with the buyer.
- Reuse native parsing, retrieval, agent execution, models, existing Paddle checkout/webhook infrastructure and Vue components. Publish to staging only and test Sandbox end to end.

- Support approved zero-price services without checkout or subscription records, retaining buyer-owned model usage and the same resource scope.
- Copy the complete current Taylor library and persona into isolated staging delivery assets, verifying documents, chunks, indexes and available derived data without modifying production.
- Hide product-page subscription-management buttons while retaining the order-management entry.
- Show purchased services in the existing knowledge workspace, retaining locked cards after expiry and exposing published Wiki and graph browsing through the existing subscription authorization. Source files, agent configuration and all writes remain private.

## Capabilities

### New Capabilities
- `creator-marketplace`: Reviewed knowledge-service catalog, creator submissions, independent recurring access, order management, and scoped native chat use.

### Modified Capabilities
None. Existing membership entitlements and standard upstream sharing remain separate and behavior-compatible.

## Impact

Go application types/repositories/services/handlers, additive SQL migrations, native session authorization and retrieval scope, Vue market/order/admin/creator views, existing Paddle integration adapters, staging-only catalog fixtures and deployment verification. No new runtime, billing provider, production deployment, automatic creator payouts, or bulk asset migration engine.
