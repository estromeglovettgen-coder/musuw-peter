# 本地代理与品牌补全

- Peter 在语言包装载处将显示文案中的 Musuw 替换为火种；保留 URL、API 字段、协议头、存储键、许可证与原始业务内容。FAQ 下载示例复用同一转换。
- 原生工作区使用 Bearer 认证。本地开发/预览代理不向北京转发共享于各 localhost 端口的 Cookie，常规 Musuw cookie 认证模式保持原样。网关 HTML 错误转换为对应语言的短提示。
- 本机全局 TUN 路径曾使北京 SSH 在密钥交换前关闭，也使 Node 开发代理的 HTTPS 握手间歇失败。北京专用 SSH 配置绑定物理网卡直连；连接真实北京 API 的本地 UI 预览使用只监听 127.0.0.1 的 SSH 转发，线上仍由原有 nginx 同源转发。
