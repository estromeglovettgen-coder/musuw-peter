# Optional public-site analytics

Prepare GA4 for the public Musuw website without measuring authenticated application content. The account owner completes provider setup and supplies the public measurement ID separately; preparation does not claim a live connection.

Reuse the existing React footer, buttons, theme variables and Cloudflare storefront workflow. Add no dependency or server service. Scope excludes app/auth, business conversion tracking, advertising, UTM persistence and search-engine account administration.
