## Why

Musuw has server-rendered public content and a sitemap, but homepage language depends on cookies/region and existing tutorials lack discoverable homepage links. Complete the bounded SEO foundations before investing in more content or distribution, while distinguishing deployment success from search indexing.

## What Changes

- Give Chinese and English homepages stable `/` and `/en` URLs with reciprocal language annotations; redirect legacy language parameters and www document URLs to the canonical destination.
- Preserve existing article URLs, regional pricing, account handoff, privacy boundaries and the partner demonstration.
- Clarify bilingual search titles/descriptions; link existing guides and comparisons from the homepage and preserve language in navigation.
- Improve existing guide headings, verifiable product comparison details, dates and page/website structured data.
- Verify actual GSC index reasons and mobile evidence, then validate and deploy through the existing GitHub storefront workflow.

## Capabilities

### New Capabilities
- `public-seo-foundations`: Stable crawlable language variants, canonical public navigation, factual existing content and verifiable release acceptance.

### Modified Capabilities
None.

## Impact

Storefront React rendering, static prerendering, Cloudflare Worker document routing, sitemap and deployment smoke checks. No database, application business logic, model calls, payment testing, new analytics collection or dependencies. No ranking/indexing guarantees or bulk content/link purchases.
