## Context

来源项目已具备标准库 Python、curl、原图独立上传、角色编译、SQLite 持久任务、去重、响应日志与明确拒绝／未知状态。生产火种已有原生登录、独立用户 tenant 和单一 firebilling 事务账本。来源私有资料、旧任务和 `.env` 不进入版本控制。

## Goals / Non-Goals

**Goals:** 完整复用工作台和生成实现，通过原生账号使用，素材与历史按用户隔离；套餐按张发放；普通账号四图合成真实成功。

**Non-Goals:** 不重写生图引擎，不公开供应商 key，不同步来源历史任务，不上线支付，不开放普通用户沙箱／Skills，不改变聊天模型、课程与检索。

## Decisions

- 将来源运行代码和必要静态资源复制到 `tools/fire-showcase`，保存原文件哈希／来源；仅增加生产适配，原本机项目保持独立。服务器复用来源凭据，保存至受限 env 文件。
- Vue 原生侧栏的智能体下方新增“展示面”，右侧承载已有工作台。静态路径 `/tools/fire-showcase/`；私有请求由原生认证的 `/api/v1/fire-showcase` 转发。客户端普通请求不能设置可信用户 header。
- Python 侧车不对公网发布；可信桥接 token 和原生认证派生的用户／tenant 标识选取独立资料目录。复用 GenerationStore／GenerationWorker；单个有界 dispatcher 调度多个用户，避免一用户一无限线程。重启保留任务，并只重试记账／本地恢复，不重发未知供应商请求。
- 私有图片采用原生 JWT 验证；图片 GET 可使用限定资产路径、短时 HttpOnly／Secure／SameSite 认证 cookie。只由已验证的原生会话签发，URL 绑定用户；Cache-Control no-store，跨用户、伪造 header 与旧登录失效均需拒绝。浏览器缓存／草稿也按原生用户命名空间隔离。
- firebilling 增加 `image_limit/used_images/reserved_images` 和按用户／任务的幂等账本。0 表示未赠送，不表示无限；真实管理员维护免扣。有效期与暂停统一校验，图片不因为聊天 Token 或问答条数耗尽而禁用，也不消耗两者。
- 生成之前原子预占一张，保存成功交付后结算一张；明确未提交／拒绝释放，未知结果保留预占。计费回调使用私有内部桥接认证，不能由普通用户假报成功或失败。失败的记账可以幂等恢复；未知预占有管理员显式结算／释放路径，不能默默开始新周期丢账。
- 管理员套餐、开户覆盖、追加、续费与单用户累计上限继续复用原账本。旧套餐／用户默认图片0，无免费供应商调用。模糊字段与显式0保持可区分，原幂等指纹兼容。

## Risks / Trade-offs

- 上游可能断连后扣费：保留未知任务和预占、人工确认，禁止自动生成重试。
- 原站脚本使用绝对路径及公共 localStorage：生产桥接收敛同源路径，用户前缀隔离；图片原字节不重编码。
- 图片和账本位于不同持久层：原子预占发生在出站之前，结果持久日志与幂等回调实现可恢复结算，后台不得重复出站补偿。
- 系统盘仅40GB：部署前快照及空间检查，仅增加轻量侧车；限制并发，不删除用户图片、课程或回退。

## Migration Plan

先离线／真实本地接口验证，再保存生产数据库和配置快照；新增原生PG／SQLite迁移，部署仅内网侧车、原生后端、Peter profile前端及静态代理。验证新普通用户、未授权访问、额度边界、四原图成功及结果下载；清理临时账号。回退保留新迁移文件，暂停图片入口，不Down或恢复覆盖用户后续数据。
