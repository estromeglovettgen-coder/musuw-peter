## Context

当前每位用户可原生拥有独立 tenant，已有系统管理员开户、原生共享知识库、模型 usage 和 UI。已有 OpenRouter 额度按金额计费，与该产品 Token 套餐语义不同，不混用或再建账号密码系统。

## Goals / Non-Goals

完成真实开户到使用、额度耗尽、赠送续费的闭环；公共课程只读、私有数据隔离、管理员无用户额度副作用。不上线在线支付，不复制课程/密钥，不关闭 Skills/沙箱；允许用户正常编辑自己的资料。

## Decisions

- 单一 firebilling 模块持有套餐、有效期、Token 账本、原子预约与结算规则。原生 HTTP/SDK 调用适配器从可信身份解析实际扣费用户；跨源检索不改变扣费身份。
- 每次供应商调用只结算一次，多轮和辅助调用都计入。输入已经包含的缓存 Token 不再次相加，输出中的思考 Token 不再重复增加。
- 优先供应商使用统计。无统计的文本模型采用已有分词能力计量并标注 estimated，不伪称实际供应商统计；传输失败无使用量释放预约，已产生用量的失败仍记真实消耗。
- 预约和结算为数据库原子变更，阻止并发超卖；已启动调用可完成并结算真实消耗，下一调用在额度不足/过期/停用时拒绝。断流/重启未知调用保留可审计状态，不能静默免费或重复扣款。
- 有效期为开通时刻起 N×24 小时 UTC。未过期续费延长原到期日并累加余额；已过期从当前重新起算且不复活过期余额。纯追加不延期。有效调用未结清时不能重置其所属周期。
- 调整请求必须有 operation_id，同一内容重试不重复赠送，不同内容复用键返回冲突。套餐变更不回写已发放的快照。所有管理动作记录操作者和前后状态。
- 系统管理员维护免用户扣费；普通身份/API/后台任务不能借共享课程、原生 API 或匿名任务绕过额度。不开公网管理密钥/明文密码查询。
- 复用 native AdminCreateUser 及事务绑定 repository，开户、资源准备与初始套餐一并提交；重试成功开户只回既有账号，不重复明文密码。
- 独立 tenant 维护个人会话、目标、文件、记忆；共享仅授予指定课程只读访问，Taylor 投影运行于本人工作区。模型访问仅为配置声明的受管资源，不借源 tenant 读取私有数据。
- 正常 UI 恢复原生智能体/深度两类选择而不暴露模型；网页导入入口隐藏。套餐和管理页沿用 Musuw 页面结构与交互，数据通过同源原生 Bearer 鉴权接口取得。

## Risks / Trade-offs

供应商使用统计可能晚于断流，保留预约与审计状态，不能把未知当作零。无统计的适配器计量明确标为分词估算。配置或数据库故障 fail closed；管理员恢复路径必须可用。数据库仅新增表，生产先快照并保留旧镜像/前端，关闭特性或回滚不会删除账本和原有数据。

## Verification

SQLite 与 PostgreSQL 验证真实事务/并发/幂等；原生两个普通账号验证读写隔离与额度不串号；模型 fixture 验证输入/输出/缓存/思考/重试/流式/取消/后台/管理员；真实 DeepSeek 和 UI 完成有额度/无额度/到期/赠送/续费/追加。生产检查所有既有知识数据和配置不受损，验收清单通过后完成 goal。
