## Why

火种需要按用户提供可管理的限时 Token 套餐，原有 Musuw 金额额度不能代表该产品的使用量。用户必须默认取得共享课程与泰勒，同时保持个人资料隔离，运营人员可安全开户、赠送和续费。

## What Changes

- 原生开户支持自定义或默认简洁账号/随机密码，独立个人工作区，共享只读课程和本地泰勒默认配置；密码只在提交成功后显示一次。
- 增加可配置 N 天、整期 Token 额度的套餐及赠送、续费、追加、延期、停用/恢复和幂等审计。
- 所有用户触发模型调用统一在调用层计量，优先真实输入/输出 Token；未回传时采用明确标记的文本分词计量，避免以次数或金额冒充。管理员维护不扣普通用户。
- 用户首页展示有效期、额度和使用量，模型能力到期/耗尽时服务端拒绝，历史内容仍可阅读。
- 复用 Musuw 的 UI 和原生后台权限，恢复智能体选择、隐藏模型与网页导入入口。

## Capabilities

### New Capabilities

- `fire-token-billing`: 用户级 Token 套餐、模型调用计量、幂等账本和后台调整。
- `fire-managed-accounts`: 原生独立账号创建、默认资源、共享只读课程和严格个人隔离。
- `fire-workspace-surface`: 首页套餐、原生智能体/深度选择及定制管理入口。

### Modified Capabilities

无。此能力仅在北京火种显式开启，不改变其他产品的支付或套餐契约。

## Impact

原生 Go 模型调用、鉴权、开户、共享读取与新增数据库迁移，Vue 用户菜单/管理页面/上传入口，auth 原生用户名登录适配，北京配置及发布。保留既有课程、Wiki、图谱、用户数据和其他服务商解析设置；不接支付网关，不产生订阅或信用卡扣费。
