# 通用销售知识：情感课程咨询简版

> **资料性质：人工编写的通用方法，不是 Peter 的个人销售理论、真实聊天或课程事实。** 用于试用独立的通用销售知识库；具体课程信息以 Peter 提供的最新资料为准。

**通用库检索句**：发现 → 匹配 → 验证 → 跟进。先发现具体需求，再匹配已核实的课程内容，验证客户是否理解和认可这个匹配，最后按约定跟进。

## 1. 发现需求：先问具体情境

先确认客户想改变什么、最近一次什么时候发生、当时怎么做、希望有什么不同。一次问一个主要问题，避免连续盘问。把客户原话、人工备注和销售推断分开；不以“问价格”“看了视频”等单一行为判断购买意愿。

**示例提问**：「最近一次让你觉得‘又变回老样子’的情境是什么？」

## 2. 匹配：用可核实内容逐项对照

将客户目标与当前课程说明中的内容、练习方式、时间要求和服务范围逐项对照。能对应的说清依据，不能确认的标为待核实；若目标明显超出课程范围，直接说明。只讨论客户自己表达的需求，不承诺关系结果或个人改变一定发生。

**验证匹配**：简要复述对照结果，问客户是否解决了他关心的问题；若理解有偏差，回到需求澄清，不把沉默当作认可。

**示例表达**：「你想练的是拒绝时的表达。我先核对课程是否覆盖这个场景，以及练习和时间安排，再判断适不适合。」

## 3. 处理异议：先辨别真正的问题

面对“太贵”“没时间”“怕没用”，先确认客户在意的是费用承受、时间安排，还是过去的失望经历。依据最新价格与服务说明回答事实，不能编造优惠、名额、退款或成功率。客户仍有顾虑时，提供资料和思考空间，不催促决定。

**示例提问**：「你现在更需要确认具体需要投入多少时间，还是担心学过后难以应用？」

## 4. 跟进：围绕上次未解决的问题

只有在客户同意或已有合理联系约定时跟进。先回顾上次的具体问题，再给一条有用的新信息或一个简短问题；没有新信息就不要反复催促。把实际发送、客户回复和下一步约定记入该客户的记录，AI 草稿不能记作已发送。

**示例表达**：「上次你想确认时间安排。我已找到当前说明，发给你参考；如果你看完发现不适合现在安排，也完全可以先放一放。」

## 5. 边界：尊重选择和信息真实性

不制造羞耻、焦虑或“错过就失去机会”的压力；不把正常关系困扰诊断成心理疾病。涉及严重心理危机、暴力或医疗问题时，停止把课程作为解决方案，建议寻求相应专业或紧急支持。客户明确拒绝后停止推销。客户资料仅用于获授权的服务场景，不将私聊自动当作公共案例。

## 给销售助手的简短输出顺序

1. **已知事实**：客户原话与来源。
2. **判断与待确认点**：明确哪些只是推测，优先补问一个关键问题。
3. **课程匹配**：仅引用已核实的课程资料，缺失则写“待核实”。
4. **可编辑回复与下一步**：提供简短草稿，尊重客户节奏；不标记为已发送或已成交。
