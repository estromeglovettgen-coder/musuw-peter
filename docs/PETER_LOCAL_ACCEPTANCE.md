## 开放范围

沿用原生配置、存储、鉴权和执行服务，没有另建一套配置引擎。

| 范围 | 可编辑内容 | 显示条件 |
| --- | --- | --- |
| 基本信息 | 名称、描述、运行模式、类型预设、模型、记忆开关 | 内置智能体仍保留原生命名和模式限制，可编辑其运行配置 |
| 模型配置 | 对话/查询理解/ReRank 模型，温度、输出长度、思考、引用 | 按运行模式和资源要求显示 |
| 提示词 | 系统、上下文、意图、查询改写、检索兜底 | 高级检索提示词用于普通问答，改写/知识库开关决定适用项 |
| 知识和对话 | 知识库范围、历史轮数、检索阈值、FAQ、记忆、问题推荐 | 知识库和相关模型需先配置 |
| 执行能力 | 工具、迭代与时间限制、联网、MCP、技能/沙箱选择、附件模型和文件类型 | 只显示当前模式适用的原生项；外部服务需独立配置 |
| 模型管理 | 服务商、模型名、地址、API Key、请求头等 | 保留原生角色权限及服务端凭据保护 |

全局设置只保留常规、用户信息、模型、长期记忆、我的记忆、MCP、IM、网页嵌入。计费、知识市场、组织和系统运维等入口隐藏，旧页面链接也会转走。界面隐藏不替代服务端权限检查。

## 已验证的链路

1. 原生账号登录；本机管理员可以进入模型管理和完整适用的智能体编辑器。
2. 在浏览器添加受控模型，填写地址和测试凭据，测试连接、保存、重新打开。正常模型查询只返回凭据“已配置”状态，不返回明文 Key。
3. 模型地址改为受控服务不存在的路径，浏览器明确显示“API 端点不存在”；恢复正确地址后显示“连接成功”。错误地址没有保存。
4. 浏览器创建“Peter 本地验收助手”，保存系统提示词、模型和输出上限 777；API 重新读取与浏览器保存结果一致。
5. 普通问答和智能推理分别完成创建、修改、重读、复制、对话和删除测试数据。受控模型收到正确模型名、鉴权、提示词、温度 0.2、输出上限 333，响应经原生聊天接口返回。
6. 使用用户指定的临时 DeepSeek Key 完成真实连通测试，并在浏览器发送测试消息。持久化会话中确认真实回复为 `PETER_OK`，模型绑定正确。这个检查与固定回复的本地测试服务分开记录。
7. 系统提示词与上下文模板切换后，浏览器实际样式确认每次只有一个提示词面板可见；修复了旧样式 `display: flex !important` 覆盖 `v-show` 的问题。
8. 设置菜单只显示上述八项；原 `section=usage` 链接转到常规设置，侧边栏与智能体列表不显示市场入口。
9. Standard 内置智能体覆盖配置的详情、列表、复制、二次编辑、租户隔离和禁止删除，由真实 SQLite repository 测试验证；Lite 不可编辑约束保持。Standard 单独配置的查询模型不会被单次聊天选择覆盖。
10. 本地数据库迁移包含智能体编辑器读取的技能元数据表；全新初始化和旧 SQLite 数据库升级测试通过，原数据保留。

11. 重启后原生登录、模型、智能体及凭据仍可用；使用保存的 DeepSeek 凭据再次连接成功，无需重新输入 Key。重启后的两种聊天模式受控复验也全部通过。

重启和最终复验结果保存在本机 `.runtime/peter/acceptance-results.json`、`.runtime/peter/live-acceptance.json` 与 `.runtime/peter/restart-acceptance.json`。不把含本机账号或会话数据的运行目录提交到仓库。

## 集中复核

本轮复核检查了编辑入口、配置读写与运行时消费、Lite 兼容、权限隔离、凭据读回、隐藏页面直达和本地重启。发现并修复了内置配置被忽略、独立查询模型被覆盖、SQLite 技能元数据缺表、提示词面板隐藏失效等验收阻断。隐藏市场组件仍会出现空标题的问题也已关闭。剩余外部依赖和部署边界见下文，没有将“配置入口可见”写成“所有外部服务均已实测”。

## 验收边界

- 真实付费服务只验收了这次提供的 DeepSeek 对话模型。其他厂商、Embedding、ReRank、视觉、语音并未逐一实测，不能据此宣称全部服务已经可用。
- 此本地环境没有启动文档解析服务、图数据库或执行沙箱。相关选择入口保留，实际执行需要配置对应依赖；隐藏的全局运维界面不在这一阶段重新开放。
- 内置智能体保留原生默认配置；涉及尚未配置的模型、知识检索或附件服务时，会要求补齐配置。可直接选择“Peter DeepSeek 验收”测试真实对话。
- 本机 SQLite 用于独立验收；最终部署方式和阿里云数据库方案留到后续阶段确认。
- 当前启动方式是本地开发进程，并非开机常驻服务。重启进程保留数据；关闭启动终端需重新执行 `npm run dev`。
