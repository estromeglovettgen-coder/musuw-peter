# 知识市场运营指南

知识市场销售指定智能体及其已审核知识库的限时使用权，包含问答、已发布 Wiki 阅读和知识图谱浏览。平台持有一份独立交付资产，所有获得授权的买家共用；商品订阅与 Musuw 会员、模型额度分别管理。

本次市场交付未部署生产。以下说明定义操作规则，不代表生产已开售；发布与环境状态以 [部署流程](DEPLOYMENT.md)、[staging 运维](STAGING_OPERATIONS.md) 和 [Paddle Live 就绪检查](PADDLE_LIVE_READINESS.md) 为准。验收记录保留在 artifacts，不作为日常操作步骤。

## 入口与角色

| 入口 | 使用者与用途 |
| --- | --- |
| `/platform/creator-products` | 普通 Max 创作者投稿、查看审核反馈、修改后重提。 |
| `/platform/marketplace-admin` | 系统管理员审核、绑定平台资产和 Paddle 价格、上架／下架。 |
| `/platform/marketplace` | 买家浏览商品、付款、开始提问。 |
| `/platform/knowledge-bases` | 买家管理自己的知识库，并查看只读的已订阅知识库。 |
| `/platform/orders` | 买家查看商品订阅与付款记录、进入对应 Paddle Portal。 |

普通创作者必须具有当前有效的 Max 资格；Free、Pro 不能创建或提交商品。平台管理员使用自己的管理权限完成运营，不以给买家开会员代替商品授权。

## 投稿、接收素材与发布

1. 创作者填写名称、介绍、分类、月费、示例问题、联系方式和内容授权说明，选择自己拥有的智能体与知识库，并确认有权发布。保存草稿后提交审核。
2. 管理员核对授权、内容质量及实际交付范围。需修改时填写原因并退回；创作者查看反馈、编辑草稿后重新提交。已发布商品不能由普通创作者直接修改，发布配置由平台处理。
3. 平台在自己的账户内使用现有建库、原生文本／文件导入功能接收获授权素材，确认解析完成且可检索，再创建专属智能体并绑定这些知识库。审核交付必须选择平台自己的资产，不能直接以创作者租户中的资源 ID 代替平台副本。
4. 在市场管理中选择平台交付智能体与知识库；付费商品填写匹配的 Paddle 商品和月／年价格，免费商品将月费设为 0 且不绑定 Paddle。确认后通过并上架。审批仍校验资产所有权，使用平台内置模型配置，默认 DeepSeek Flash。已经审核过的商品不能直接在免费与付费之间转换，应建立新商品。

平台副本由现有原生功能人工建立，不提供自动跨租户发布或持续同步引擎。创作者源库后续修改不会自动进入已交付副本；更新素材需由平台重新接收、审核和维护。联系方式、授权说明和审核意见只用于创作者与管理员工作流，不进入买家目录。

## Paddle 环境与价格

Staging 只使用 `staging.musuw.com`、Paddle Sandbox 和测试身份。生产使用 `app.musuw.com` 与 Paddle Live，必须在生产环境单独准备并校验商品、价格、浏览器配置及 webhook；Sandbox 商品／价格 ID 和凭据不能混入 Live。环境及密钥管理沿用 [集成说明](SECRETS_AND_INTEGRATIONS.md)。

每个付费市场商品绑定同一 Paddle 环境中同一商品下的两条 active 价格：USD、无试用，周期分别为每月和每年；每次结账数量为 1。年价严格等于月价的 10 倍，年付服务期为 **12 个月**。例如月价 `$5` 对应年价 `$50`；接口金额使用美元分，即 `500` 与 `5000`。Paddle 结账展示最终税费与金额，后台会重新核验真实价格，不能只修改页面数字。免费商品月／年价格均为 0，不绑定 Paddle 商品或价格。

## 买家付款、提问与隐私

买家在商品详情选择月付或年付并订阅。应用收到可信付款确认后开通；浏览器结账完成提示本身不能授予访问权。仍在同步时使用刷新状态或订单管理核对，支付失败在 Paddle 中修正并重试对应账单。

已上架免费商品供登录用户直接开始提问，不创建订单、订阅或结账。每次提问同样校验已审核资产范围，消耗使用者自己的模型额度；下架后停止新问题，保留已有对话。免费不代表模型用量无限。

有效订阅通过「开始提问」进入绑定该商品的原生聊天，默认使用 Flash，并消耗**买家自己的 Musuw 模型额度**；商品费不包含额外模型额度，也不会把 Free 买家升级为会员。平台交付账户不承担买家问答的模型用量。会话和历史保留商品绑定，买家可从已有会话继续查看回答与必要引用。

已实际购买的知识服务会显示在知识库列表中，标记为只读订阅库。买家可阅读其已发布 Wiki、搜索条目和浏览图谱，也可以进入绑定智能体的问答。平台资产不会复制到每个买家账户，浏览已有内容不调用模型，也不占用买家存储。

只读浏览不授予源提示词、原始全文文档、其他知识库、历史修订或批量下载原文的权限；不提供上传、编辑、删除、重新生成、AI 修复、回滚或共享管理。每次读取均验证当前订阅和已审核知识库范围，不能依靠已知链接绕过权限。已过期／撤销的订阅保留锁定卡片；仅有未付款结账不会获得可用知识库。历史会话按原规则保留。创作者不会因发布或出售商品获得读取买家会话、问题或回答的权限。

## 订单、取消、退款与下架

订单管理分别展示商品订阅、付款记录和 Musuw 会员入口。入口保留在市场页顶部，左侧栏不再重复显示；商品详情不显示管理订阅按钮。「管理订阅」仅在订单管理中进入对应商品的 Paddle Portal；「管理会员」处理 Musuw 会员，二者不能互相替代。

| 操作／事件 | 操作含义与应用行为 |
| --- | --- |
| 下架商品 | 停止目录展示和新订阅；有效已付期限内的买家仍可从订单使用。下架不会自动取消续费或退款。 |
| 取消期末续费 | 同步后显示取消安排；已付期限内继续可用，到期后不能开始新问答或继续读取 Wiki／图谱。 |
| 已生效的立即取消、暂停或已付期限结束 | 对应商品不能继续开始问答或读取 Wiki／图谱。其他商品与 Musuw 会员分别按自己的状态处理。 |
| 续费失败 | 不延长已付期限；如尚有有效已付期限，使用权按该期限保留。通过 Portal 处理原账单，确认付款和应用同步后恢复／延长授权。 |
| 当前已付周期的全额退款获批准 | 撤销该周期使用权，付款记录标记退款；待处理退款请求不等于获批准。 |
| 旧周期全额退款或部分退款 | 旧周期退款不撤销后续独立付款取得的新周期；部分退款不自动撤销整期授权，需核对订阅的实际处理要求。 |

**退款不等于取消订阅。** 退款后 Paddle 订阅可能仍未终结，包括已经安排期末取消的情况。此时商品不可提问，也不能另开重复订阅；详情显示现有状态并提示前往订单管理处理原订阅。只有旧订阅真正进入允许重新购买的终态，才可新建结账。不要通过反复创建订单或手工改变应用状态绕过限制。

永久停止交付不能只点下架：先停止新售，再在 Paddle 明确处理现存订阅的取消及应退费用，核对应用同步和剩余交付期限，最后处理平台资产。当前没有一键永久撤回并自动结算全部买家的功能；不要删除平台知识库来中断仍应履行的已付服务。

## Staging 素材范围

Staging 的 Taylor 商品以完整生产资料快照为交付目标，范围包含原始文件、已解析内容、向量、Wiki、图谱与专属智能体；迁移完成后才可按实际核对数量更新商品说明。生产只读，目标必须使用独立的 staging 数据库、对象存储和图谱服务，不重新调用模型解析全库。保留历史删除状态，旧单篇样例停用检索但保留历史引用。另有三个付费 Sandbox 短文样例及三个独立免费短文样例；免费样例不替换或重定价已有付费商品。当前具体数量及迁移验收记录以发布证据为准。
