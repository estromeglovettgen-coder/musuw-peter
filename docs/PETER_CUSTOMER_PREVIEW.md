# Peter 客户工作区 · 第一版本地预览

初版按用户要求快速实现，本地提供虚构数据，由用户进行功能验收；初版未运行自动化测试或浏览器功能验收。后续针对已报告界面问题的诊断记录见文末。仅在本地运行。

## 打开方式

运行 `npm run dev`，打开 <http://127.0.0.1:4217/platform/customers>。使用原来的本地账号。

准备演示数据：`npm run peter:seed-customers`。脚本仅访问本机 18187 端口，读取未跟踪的本地预览账号，复用已配置的 DeepSeek 模型，不修改已有模型凭据。重复执行会保留同名的演示资料和已有会话。

## 这版可以查看什么

- 「工作区 → 客户」：按名字、联系方式、状态和标签查看客户，新建独立客户项目。
- 新建和编辑客户共用完整面板：客户名称、说明、状态、标签、联系方式、备注、关联公共知识库、画像条目，以及原有模型、解析、图像/音频、分块、Wiki、图谱等配置。
- 客户列表右上角「客户设置 → 客户模板」：新建、编辑、复制和删除客户类型模板，使用同一完整配置面板。点「完成配置」返回设置，再点「保存」生效。新建客户选择模板便可套用，之后仍能单独修改。
- 「客户设置 → 状态与标签」：添加、删除选项，拖动状态或标签的手柄调整顺序；也可聚焦手柄后使用方向键。没有模板时，第一项作为创建默认状态。删除选项不改动已有客户资料，已有值仍可筛选。
- 「聊天资料」可在新建或编辑时选传原始聊天记录、截图和文件；先保存配置再上传，逐份显示结果。失败时保留当前客户和成功文件，可重试失败文件或先进入客户。
- 客户概览：客户名片、置顶备注、关联公共知识库、客户画像和最近记录。
- 新建客户自动选择生成的画像 Wiki，无需预先指定条目；已有 Wiki 的客户可在编辑中选择「首页显示的客户画像」。
- 客户资料、Wiki 和图谱：复用原来的文档、Wiki 页面及 Wiki 关系图；每个客户使用自己的知识库。
- AI 对话：会话绑定客户，切换智能体不改变客户归属；选择其他客户会打开另一条客户会话。
- 首页 `@` 客户：独立“客户”分组，发送时建立客户绑定，不受销售方法知识库的选择范围限制。客户/知识库标签可点击进入详情。附件默认归档，可在智能体编辑的基本信息中关闭并持久保存；对话页不再展示客户横栏或归档开关。

本轮对话界面修正已在本地核对：指定知识库的销售智能体仍能列出三位演示客户；选 Ben 会替换 Ryan 标签；客户标签进入对应客户项目，销售经验标签进入对应公共知识库；叉号不触发跳转。客户会话原有横栏已移除，绑定客户通过已选标签显示。归档偏好已验证保存、重开和数据库落盘，并恢复演示智能体的默认开启状态。前端构建、最终类型检查、原生后端构建和本地重启均通过，首页 HTTP 200。没有发送模型请求或触发资料解析。

观察：部分对话的模型胶囊仍显示模型 ID，智能体编辑器能显示正确模型名称；本轮未扩展处理这一既有展示问题，实际模型调用留给用户验收。
- 沟通、跟进和备注：作为客户的手动资料保存，通过原有整理流程处理；不自动升级为公共销售案例。
- 「客户设置」：直接编辑原有「Wiki 提取重点」和「Wiki 内容生成要求」，没有增加第三套分析提示词。
- 「Peter 销售助手」：预制、可编辑的普通智能体，Peter 可以改提示词、模型、工具等，或新建其他智能体。

## 当前边界

- 这是本地第一版，功能验收尚待用户完成。编译和进程启动不代表完整链路已验收。
- 新客户默认使用 Wiki 整理和问答，无需先配置 Embedding。原有 RAG 设置继续保留，启用前需配置对应模型。
- 目前概览读取最近 100 份资料与 50 条会话；全部原始文件仍可在资料页查看。大规模时间线翻页属于后续完善项。
- 截图理解、扫描件、音频和复杂文件解析需要相应视觉/语音模型及文档解析服务；本地尚未配齐。演示 Wiki 关系图不依赖 Neo4j；独立实体抽取图谱依赖对应服务。
- 修改 Wiki 要求影响后续整理或重新处理，不会立即改写已有页面。
- 暂无自动提醒、CRM 外部同步、自动案例入库或自定义字段构建器。

## 数据与恢复

本地账号、模型密钥、上传文件和 SQLite 数据均在未跟踪的 `.runtime/peter/` 下。新增迁移增加客户信息、会话绑定和工作区客户选项字段；重启前已使用 SQLite 备份接口保存迁移前快照。回退时先停止本地服务，配套回退代码和数据库备份。

私有 Standard 版本不再受面向公共 Lite 产品的一个知识库、十份文档及视频套餐限制；模型配置和原生权限校验保持在各自原有链路。

## 2026-09-29 · 客户类型模板与拖动排序

按最新明确需求补齐可复用模板，保存到既有工作区 customer_config JSON，不增加数据表、迁移或处理引擎。模板保存模型引用、Wiki 内容和提取要求、解析/图像/音频/存储/分块/图谱/高级配置，以及默认状态、标签、备注和公共知识库关联。模板不保存客户姓名、联系方式、实际来源文件、生成的 Wiki 条目或服务商密钥。新建客户套用时保留个人名称、说明、联系方式、已填写的备注和待上传文件；之后改动模板不追改既有客户。

本地留下「课程咨询（演示模板）」「学员交付（演示模板）」两套可编辑示例，以及由交付模板创建的虚构客户「Casey（模板演示）」。没有上传来源或调用模型。浏览器定点核对了模板新增、复制、两套独立内容编辑、保存后刷新读取、套用后的状态/Wiki 回填以及个人字段保留。原生拖动事件确认状态能跨行换位；键盘排序也生效，并恢复原状态顺序。标签复用同一排序处理函数，实际多标签拖动、资料解析及完整业务验收仍交由用户。

数据库只读核对确认新客户保存的 Wiki/分块配置与选中模板一致，手写备注和联系方式保留；原有客户和公共知识库资料未变。集中代码审阅覆盖模板与个人资料边界、原生配置序列化/回填、工作区管理权限、旧版仅保存状态/标签时不丢模板、配置大小限制和弹窗关闭/返回。后端、前端编译及本地健康检查通过；没有运行自动化业务测试。既有前端资源体积和图谱/Mermaid 循环依赖构建警告保留为原有事项。
