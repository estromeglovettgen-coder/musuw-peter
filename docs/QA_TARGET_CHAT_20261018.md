# 目标与知识库联合对话 QA

范围：修复课程库与一个目标同时选择后消息未发送、对话区只剩快捷问题的问题；隐藏火种技能设置入口。保留原生绑定、授权、共享课程检索与既有用户资料。

验收通过后才上线；线上以独立临时账号和虚构目标验证，不消耗现有用户额度。列表中的项目需有当轮证据才可勾选。

- [ ] 从首页同时选择课程库和一个目标，第一条消息、回复和输入框均可见。
- [ ] 已有普通会话选目标后创建绑定会话，原消息自动发出一次。
- [ ] 已绑定目标继续对话，不重复建会话，不丢课程库。
- [ ] 切换另一个目标，新消息只发往新目标，旧会话消息保留。
- [ ] 刷新绑定会话，历史、输入框和目标绑定正常恢复。
- [ ] 仅知识库、仅目标和普通对话保持正常。
- [ ] 多目标拒绝并显示原因，输入不丢失；准备失败可重试。
- [ ] 会话读取、建会话和模型错误不会卡死，能够重试或继续输入。
- [ ] 慢响应与重复点击不导致重复发出消息。
- [ ] 桌面和手机对话正文、输入区都可见。
- [ ] 普通用户与管理员的技能设置入口隐藏，直接入口正常回退，保留代码配置。
- [ ] 目标隔离与原有附件归档回归通过。
- [ ] 类型检查、生产构建和一次集中反向审查通过。
- [ ] 北京上线后真实首条消息、续聊、刷新和课程引用验证通过；数据未改动，临时账号已清理。

追加验收范围（2026-10-19）：
