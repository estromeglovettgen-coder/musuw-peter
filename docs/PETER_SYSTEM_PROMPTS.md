# Peter 系统提示词

入口为账号菜单中的设置 → 系统提示词，或 `/platform/settings?section=system-prompts`。复用现有工作区权限，管理员可以保存和恢复默认，其他有设置访问权限的成员只读。

## 使用与生效

先选功能分类及提示词，编辑正文后保存。标出的模板变量用于传入实际问题、资料、历史或变更内容；变量名称必须保留，缺失变量和错误语法会阻止保存。可以点击变量插入到光标位置。恢复默认需要确认，未保存的编辑在切换时也需要确认。

配置属于当前工作区，单条更新不会覆盖其他条目。普通对话、智能推理、文件摘要、推荐问题、图谱提取、Wiki、图片/扫描件、视频、表格及长期记忆的对应调用读取配置。异步处理任务在任务边界恢复所属工作区配置；对话标题保留发起请求的工作区快照。

智能体自行填写的规则优先于工作区默认。工作区设置改变默认规则，不强制替换已经自定义的智能体正文。

知识库的“Wiki 内容生成要求”也用于文件摘要，控制输出范围和长度；“Wiki 提取重点”控制条目筛选。两者的业务范围优先于默认模板的全面总结、长度和颗粒度建议，结构字段、来源引用及事实要求仍需保留。例如“只用写出姓名，其他一概不要写”应让摘要和新生成的 Wiki 只保留姓名。

保存不会自动重写已有摘要、Wiki 或记忆。需要重新生成或重新处理相关资料，下一次生成才使用新规则。

## 中文默认与兼容

项目内置 YAML 模板、运行时处理规则及工具说明的自然语言已中文化。代码标识、JSON 字段、引用格式、路径和变量不翻译。

已存储的智能体正文只在完全等于旧内置默认时迁移为中文；用户自己写的正文、上传资料、外部工具或第三方技能内容保持原样。翻译脚本以完整正文精确匹配，不能按关键词批量覆盖用户内容。

## 接口与持久化

- `GET /api/v1/tenants/kv/system-prompts`：目录、当前正文、中文默认、变量及是否自定义。
- `PUT /api/v1/tenants/kv/system-prompts`：提交 `{id, content}`；空正文恢复该条默认。管理员及具备相应工作区设置管理能力的 API Key 可写。
- 当前目录只提供接入真实生成流程的模板，拒绝未登记编号；正文最多 40,000 字，请求体上限 256 KiB。
- 配置存储在 Tenant 的 `system_prompt_config`。事务锁定该工作区后更新单个键，常规工作区更新不覆盖此列。
- PostgreSQL 迁移 `000111` 新增可空 JSONB，SQLite 迁移 `000030` 新增可空 TEXT。旧工作区无覆盖值时继续使用默认。回退程序可以保留该列及配置，不需要删除用户数据。
